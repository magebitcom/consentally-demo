# ConsentAlly demo stores

Static demo pages for ConsentAlly's Google Consent Mode setup, served at https://demo.consentally.com:

- `/gtag/` - a store page with the ConsentAlly tag first, then gtag.js for GA4.
- `/gtm/` - the same with Google Tag Manager.

The banner shows for visitors from every region. The source lives in the ConsentAlly monorepo under `integrations/demo-sites/`; this repository only serves a copy of its `site/` folder.

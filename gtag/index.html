How this page is set up

  1. The ConsentAlly install tag, first in <head> (store key inzhgqu7rlp73dpt).
  2. Google's gtag.js for the Google Analytics 4 property G-5DCLB8XT3F, directly after it, written as a ConsentAlly manual tag (type="text/plain" and data-ca-src), so the browser fetches nothing from Google before ConsentAlly lets it load.

ConsentAlly sets Google Consent Mode's defaults to denied before gtag.js runs and sends an update when you choose in the banner. Every visitor sees the banner, in every region.
